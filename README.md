# Form 2 Sains Bab 4 — Kesihatan Manusia

马来文与华文学习游戏，适合国文基础较弱的国中生。

- `index.html`：15张认词卡、每轮10题综合练习、分类、填空、步骤排序、简答、错题重练。
- `SUMMARY.md`：本章6大重点、得分关键词及复习问答。
- `summary.html`：手机可读、可打印的重点笔记页面。

## 使用

直接在浏览器打开 `index.html`。无须安装依赖。先学5张词卡，再做一轮10题综合练习。专项练习题数随题库而定。

学习记录保存在当前浏览器的 localStorage，不会跨手机同步。简答题由学生对照关键词自评，建议老师复核。清除浏览器资料可能会删除记录。

## GitHub Pages

在仓库 Settings → Pages 选择 Deploy from a branch，分支选择 main，目录选择 / (root)，保存后等待部署完成。
